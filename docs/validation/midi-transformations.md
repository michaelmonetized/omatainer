# Reversible MIDI transformations

Open a MIDI clip, select notes and expand MIDI transformations below the ordinary piano-roll controls. Preview prepares the selected transformation on a worker and leaves the committed clip unchanged. Restore returns the exact draft; Keep accepts the result as the next original. Apply commits the complete note/controller edit as one Undo entry. Previous/Next recall up to 32 parameter settings during the current editor session. Closing an unapplied draft uses the existing discard confirmation.

Quantize starts, ends or both using straight/triplet grids and partial strength. Start-only preserves note duration. Recombine independently shuffles, mirrors and rotates Pitch, Position, Length or Velocity, in that order, using a repeatable seed and stable selection order. Draw velocity samples with the pointer or edit them numerically; Flat, Rise, Fall, Sine, Triangle and Pulse shapes support phase, cycles, range and strength. Stretch anchors the first selected onset; Reverse reflects note endpoints across the selected phrase. Time curve integrates reciprocal speed over three editable points; optionally preserve the phrase extent. Before/after summaries show extent, total duration/gaps, overlap, mean onset shift and timing rounding. Clip and loop bounds stay explicit.

Imported notes keep their source PPQN and ordering, identities, channels and release velocities. Unique poly-pressure points follow their note. Explicit lower/upper MPE member ranges additionally associate pitch bend, channel pressure and CC74; manager and unrelated channel automation retain their timeline. Ambiguous ownership, foreign/orphan expression entering changed voices, newly overlapping expressive voices and SMF pairing changes refuse preview. Unselected notes, source metadata and labels stay exact. This does not add automatic MPE-zone inference or the separate per-note expression editor.
