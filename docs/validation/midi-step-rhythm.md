# Step entry and editable rhythms

The native MIDI piano roll now enters notes while transport is stopped. Its visible step cursor uses straight or triplet durations. Held computer keys audition independently; releasing the last key inserts the complete chord when Record steps is enabled. Space inserts a held chord or rest, Shift+Space ties the previous chord and Backspace removes the last step. Named buttons provide the same editing actions. The bounded step history refuses deletion after another edit changes the step, rather than replacing that edit.

Computer note input is explicit: enable Computer musical keyboard and focus its input button. A W S E D F T G Y H U J K cover one chromatic octave. Z/X change octave and C/V change velocity. Repeated key-down events cannot retrigger or duplicate notes. Focus loss, Tab, text entry, popups, disabling input, Apply and editor close release audition ownership. Those releases preserve independently held physical MIDI notes. Notes are not written into the renderer's clip until Apply; one Apply uses the existing guarded MIDI edit and one project Undo entry.

The rhythm generator supports up to eight voices. Each voice has an independent step count and rhythmic duration, Euclidean pulse count, rotation, density, velocity and accent interval. Swing delays odd local steps; gate controls note length. The full unsigned 64-bit seed has an exact text editor. Seeded density is repeatable; zero density/pulses are empty and full density/pulses retain every step.

Preview covers the voices' least-common period in quarter-note beats. It appends to existing draft notes unless Replace draft notes is explicit. Generated notes have ordinary stable identities and remain editable. Regeneration starts from the captured original draft rather than accumulating another pattern. Restore returns the original notes, selection and loop bounds, and refuses to overwrite later note or loop edits. Apply commits the current draft and clears preview ownership. Pitches remain explicit when harmonic context changes; conductor meter changes do not rescale quarter-note coordinates.

Work is bounded before generation: at most 64 steps per voice, 65536 steps across the common period, 8192 output notes and 262144 beats. Excessive independent periods, nonfinite values and invalid pitches/velocities fail without changing the draft. Analysis and editing run outside the audio callback.

Native egui checks cover accessible controls, complete chords, rests, ties, triplets, seeded regeneration, restore protection, Apply and Undo/Redo. The step-entry test compares the renderer's note-on/off sample positions and velocities with the intended score. Independent 5-step and 7-step rhythm fixtures compare every hit against an explicit 35-step score with rotation, swing and accents. These are software input and renderer checks; no physical controller gesture or PA listening is required or claimed.

Final software qualification: 15 focused editor checks and all 563 broader native UI checks pass with zero failures. The broader run retains 13 explicit ignored checks. Five checklist guards and compiled fixture selectors pass; the generated offline manual is synchronized. Exact source-file hashes and log paths are recorded in [the receipt](midi-step-rhythm-receipt.json).
