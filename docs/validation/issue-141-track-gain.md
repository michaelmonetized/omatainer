# Per-track source gain (#141)

The deck's `gain…` review controls a source trim separate from its fader. Off preserves unity source trim. Manual stores an explicit -120 to +12 dB override. Auto stores an explicit -40 to -6 dBFS RMS target and -12 to -1 dBFS sample-peak limit, with no more than 12 dB boost. Defaults are -18/-3 dBFS. Silence gets no automatic recommendation; unsupported attenuation and non-finite PCM are refused.

Measurement covers the complete first stereo pair or mono source as rendered by the deck. Other channels are checked for damaged non-finite PCM. RMS uses arithmetic mean-square amplitude; sample peak is the largest absolute sample. Near-full-scale samples are those at or above 0.9999. This is not integrated LUFS or true-peak measurement. The precomputed multiplier precedes the fader, EQ, filtering and effects; it cannot repair existing clipping or promise final mixed-output headroom.

Background analysis stores the measurement and default recommendation under exact source, fingerprint, digest and level algorithm version 1. It does not change playback trim. A deliberate load remeasures decoded PCM and resolves the saved policy on the worker; project recall remeasures its embedded PCM. No cached measurement controls recall. The original PCM and current deck fader stay unchanged.

Apply is one bounded history edit tied to the current immutable media receipt and measurement. Play, touch, paused preview, retained nonzero output, outgoing nonzero fades, protected performance and stale measurements refuse it. Cancel preserves the current trim. Closing a queued edit does not cancel an accepted command. UI confirmation reports renderer admission; catalog save status is separate.

Old headers migrate to Off; an old header containing gain/level fields, including null fields, is refused without overwriting the file.
