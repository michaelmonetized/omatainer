# Held loop rolls and playback direction

Each deck's existing **Roll** mode repeats the selected beat division while the original pad is held. The pad parameter changes its range. With that deck's Quantize enabled, onset waits for the selected deck division using advancing source time; otherwise it begins at the actual playhead position. Releasing a pending pad cancels its original request. The newest held roll or slice takes priority, including after a vacated owner slot is reused. Releasing it returns control to the next surviving owner. Final release restores the original advancing source timeline and loop through the existing Slip release policy.

Native **REV** toggles persistent reverse until switched off or retired by source replacement, project replacement or safety stop. It persists across ordinary pause/play. At the first file frame reverse produces silence and remains available for forward takeover; an enabled source loop wraps backward within its original interval. A native latch and independently held controller reverse controls have separate ownership. With Slip enabled, reverse also uses the existing shared background and release policy.

Native **CENSOR** reverses temporarily, then resumes the advancing forward timeline on final release. Mouse, Space, Enter, touch and assistive actions retain independent local owners; controller holds remain independent. Assistive Click toggles a hold, and explicit Press Censor/Release Censor actions are available. Losing focus, changing source, hiding the deck workspace, project replacement and safety retirement release original local holds. Required renderer admission precedes local ownership changes.
