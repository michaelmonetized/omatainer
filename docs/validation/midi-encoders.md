# Configurable encoders and high-resolution MIDI controls

Issue [#223](https://github.com/michaelmonetized/omatainer/issues/223) adds per-assignment formats, direction, scalar limits and sensitivity in the native MIDI learn editor. Absolute CC, paired 14-bit CC and pitch bend target deck pitch/gain/EQ/filter, crossfader/contour, master/headphone mix, track gain/pan/sends and effect wet levels. Relative encoders adjust those current renderer-owned values, so a GUI edit or another controller never leaves a stale private accumulator. Jog and library browsing retain ordered steps. Browser sensitivity stays one item per step; other relative assignments have positive finite sensitivity.

The editor explicitly selects offset binary, signed bit or two's complement. Offset binary has 64 stationary, lower bytes negative and higher bytes positive. Signed bit has 0 and 64 stationary, 1–63 positive and 65–127 negative magnitudes. Two's complement has 0 stationary, 1–63 positive and 64–127 negative. Inversion applies to the individual binding. Scalar minimum and maximum are finite and ordered; gain assignments can use 0–1.5, and other parameter intervals use 0–1. Pitch bend uses every 14-bit value, exact center 8192 maps to 0.5, and both endpoints remain reachable.

Standard high-resolution CC pairs use coarse controllers 0–31 and their fine controllers 32–63, on one channel and exact input port. A standard coarse update clears the old fine byte and publishes its coarse value. Fine-only updates retain the current coarse byte even after idle time. Capture waits for both bytes in a fresh gesture. Controllers that send fine then coarse can explicitly select that paired order; those complete pairs must arrive within one second. The two interpretations are never globally guessed. Reset Controllers clears its channel, System Reset clears all pairs, and mapping, routing, safety, overflow and disconnect boundaries retire partial state. Both reserved addresses participate in factory/learn conflict review. Pair state belongs to the input worker; raw callbacks keep bounded copying and atomic counters.

The behavior follows the [MIDI Association's controller table](https://midi.org/midi-1-0-control-change-messages) and the paired-controller ordering described in [RFC 6295, Appendix A.3.1](https://www.rfc-editor.org/rfc/rfc6295.html#appendix-A.3.1). [Serato's MIDI data-type documentation](https://support.serato.com/hc/en-us/articles/225065768-MIDI-Data-Types) provides the compatibility context for configurable interpretation; Omatainer's exact relative byte tables are documented above and checked exhaustively.

Native MIDI capture retains the canonical coarse address, full 14-bit value, chosen order and transformation. Preview uses that value. Actual Add, Save assignments, Save port as preset, Export, Import review and Save imported preset controls retain the same metadata through real files and native preferences reopening. Destination selectors and native preference text fields publish explicit accessible names. The action menu closes after selection; editor and Capture identities stay independent of device rows and format changes. An existing capture regression now chooses Master gain through that menu and verifies arming before delivering the wire message. Preset schema 2 and preference schema 19 migrate older omitted defaults while rejecting newer encodings or injected metadata, including explicit null fields, in old versions. Failed or ambiguous imports preserve live assignments.

Seven core checks cover all 16,384 values in both explicit pair orders and all signed-bit byte values; fine-only updates, coarse resets, timeout, channel/controller/port isolation, real mapping revisions, conflicts, finite limits, exact bend center, native file round trips and old-version refusal. Production synthetic callbacks feed the real worker and renderer. Relative adjustments follow actual current parameter state and reuse existing scalar Undo paths, with measured zero renderer heap work. One native test drives actual selectors, capture, preview, assignment, settings save, preset save/export/import and reopening. Baseline send-control Undo/persistence is not requalified by this change. Physical controller response is outside this software pass; no physical audio or MIDI device is opened.
