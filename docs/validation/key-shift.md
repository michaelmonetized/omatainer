# Independent deck key shift and chosen-key matching — #202

Open **key shift…** in the library toolbar. Each deck has independent semitone up/down controls, a reset button, its confirmed offset and its actual processing state. Supported offsets are −6 through +6 semitones. Reset changes the independent offset to zero and retains the current key-lock setting.

Choose one of the 24 major/minor target keys and press **Match chosen key**. Omatainer uses the musical key of the exact source version actually loaded, even after browsing another track. The closest same-mode offset and key lock are applied together as one undoable edit. Opposite major/minor modes and unknown source keys produce a visible refusal. Target names describe the requested result; bypass is shown separately. Source-key provenance follows the existing user-lock, saved tag and analysis rules. Sources reopened without a current catalog-load association are shown as unknown until loaded through that association.

An independent offset leaves logical tempo, source-time progression, playhead, gain, crossfader and the other deck unchanged. With key lock enabled, the tempo fader does not bend the shifted key. With key lock off, the tempo fader still bends that key normally. Retuning preserves filter history and begins with the previous output sample through the existing short transition.

Forward tempo is bounded to 50–150% for nonzero shifts. With lock enabled, that interval is also intersected with the overlap ratio 0.5–1.5 after division by the selected pitch factor. The panel reports the resulting supported tempo interval. Scratch touch, reverse and unsupported tempo explicitly bypass the requested shift and use ordinary direct resampling. Stopped/no-media states are armed, not a claim that shifted sound is playing. A zero offset preserves the preexisting renderer path exactly. New projects save offsets in state version 28; earlier state headers cannot smuggle in an offset field, including zero or null.

The pitch processor extends Omatainer's original MIT stereo-linked waveform-similarity overlap-add implementation, without a new DSP dependency or foreign allocator. This is a bounded resampling/overlap algorithm; its analytical measurements and complete mix samples do not establish human transparency, converter latency or live-stage performance. Linear source interpolation and the output Nyquist limit still apply.

At output rate S, with the processor's actual rounded hop H, let G be the within-grain pitch factor (also multiplied by tempo when lock is off). The search radius in source seconds is 0.025 × max(1, G). Conservative source lookahead and content-displacement bounds are that radius plus (2H + 1) × G / S and (H + 1) × G / S respectively. These configuration bounds vary with shift and tempo; the older zero-offset 67 ms lookahead bound is not universal. The callback retains its fixed score budget and introduces no output FIFO.
