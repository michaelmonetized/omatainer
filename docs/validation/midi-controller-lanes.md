# MIDI controller lanes

The native piano roll now edits CC, 14-bit pitch bend, channel pressure and bank/program points in quarter-note beats. The plot and virtualized point list share the original tick positions. Imported clips retain their PPQN, channel, message width, metadata and unchanged source events. New bank/program points send Bank MSB (CC 0), Bank LSB (CC 32), then the two-byte Program Change. Controller and exact patch labels persist in project schema 15; older project versions reject the new field rather than accepting it as legacy data.

Apply prepares immutable lanes and seek indexes on a worker. It validates the complete prospective native project and measures serialized metadata before admission. A concurrent project edit rejects the request; the draft remains available for another Apply. The renderer swaps prepared content without allocating. One Apply is one existing Undo/Redo entry. Cancel discards draft changes and cancels preparation without replacing the clip.

Seek and launch restore earlier scalar controller state before active notes. The bank/program chase restores selectors captured at the last Program Change, emits that program, then restores any later pending selectors. A controller exactly at the destination runs before a chased note. Source-ordered imported notes retain their wire ordering; newly drawn notes follow source controller events at the same beat. Repeated loops use the previous pass's controller state until a new point arrives. Reset All Controllers is a chase barrier for resettable controls, while volume, pan and bank/program values retain their specified state.

Stop releases owned notes and sustain. Bend, channel pressure, modulation, breath and expression return to the latest remaining managed owner on the same output/channel. With no remaining owner they return to center/zero, or 127 for expression. Volume, pan, arbitrary CC and patch values remain selected. This avoids a blanket channel reset that would silence another track. An explicit global output reset retains its existing channel-reset behavior.

RPN/NRPN selectors, data entry/increment/decrement and other channel-mode transactions retain ordinary source playback and export. Seek does not invent their state from independent scalar CC values. The existing 256-event output limit per audio block still applies; excessive density is refused visibly. The dense plot samples at most 4096 points per frame and labels that overview; its list retains every event.

Qualification uses native egui input, the actual renderer, the existing output owner with a deterministic software MIDI backend, and native project preparation. Tests check maximum-range PPQN tick preservation, two/three-byte messages, bank ordering, patch labels, stale selection, invalid values, cancelled preparation, Apply/Undo/Redo/cancel, save/reopen, concurrent edits and zero callback allocations. Seek traces verify patch/filter/bend/pressure before notes; stop traces verify shared-channel restoration and final neutral values. No physical synth or rig gesture is required or claimed.

Primary wire definitions: [MIDI 1.0 message summary](https://midi.org/summary-of-midi-1-0-messages) and [MIDI 1.0 control changes](https://midi.org/midi-1-0-control-change-messages).
