# Manage music files

Library → files… opens Music files. Capture the selected rows, or the current filtered view up to 128 tracks. Review the exact rows before Apply. Copy and Move with recovery require an existing absolute destination folder. Both install byte-verified copies without overwriting existing names and keep stable track identities, cues, grids, loops, prepared-version histories and previous locations. Move retires the original into a recovery path only after the catalog save is confirmed.

Inspect recovery to restore a pending move or Keep reviewed moved music locations to retain the new location and save its recovery record. Keeping allows another batch. Saved moves remain available after reopening the app; restoring a record verifies its exact reviewed rows and owned files, then restores the original location. Restoration refuses intervening preparation edits or occupied paths. Original audio remains recoverable; there is no permanent-delete action.

Remove reference removes only the reviewed catalog entries and rewrites their crate memberships while preserving imported provenance and source audio. Find likely duplicates offers bounded candidates. Select a pair, retained identity and preparation, then Review and Apply. Merging requires a full independent byte comparison; it keeps both prepared histories and aliases, remaps imported identities and crate memberships, and keeps both audio files. Conflicting locked grids or preparation are refused.
