# Reviewed Ableton migration and native project handoff

This implements the session migration portion of [#511](https://github.com/michaelmonetized/omatainer/issues/511) in the existing [PR #510](https://github.com/michaelmonetized/omatainer/pull/510). The complete issue remains open. See the [versioned support matrix](../ableton-migration.md) for implemented conversions and explicit playback differences.

The actual Project toolbar reviews a Live 10/11 XML or single-member gzip Set in a disposable process, retains its source XML, inventories devices and assets, and publishes a new native archive after acknowledgement. Publication checks the reviewed source again and refuses an existing destination. Open uses the ordinary unsaved-work decision. Cancel keeps the running namespace; discard installs the imported stopped session. Selected-track merge rebinds native routing and migration references in one undoable transaction.

Exact VST3 class and compatible installed binary/version relinking restores original component/controller state, normalized values and supported automation. The native instrument/effect fixture produces the expected audio after relink, merge and reopen. Unsupported engines, rack branches, formats, expression, warp behavior and routing remain retained and named. No vendor integration code is executed.

Reviewed track prints and complete mixes carry source start/body/tail and source tempo clock. Printed processing is disconnected from the editable source to prevent duplication. Both unpublished restore and saved native archive restore preserve editable MIDI, devices and routing. A saved archive can be reviewed and restored while the original Set, installation and render source are offline. Conflicting edits prevent restoration.

Private sealed memory descriptors carry bounded native containers between the application and workers. Source I/O, decode, verification, render attachment and relink happen outside the callback. Cancellation retires a killed process group without blocking the UI on kernel I/O; at most four active or retiring filesystem owners are admitted. Corrupt, truncated, oversized and malformed containers, source mutation, gzip CRC/trailing members, XML entities/depth, unavailable files and cancellation are exercised.

The final frozen generation 24 runs all eight native migration workflows successfully with the actual worker executable. Ten ordinary migration contracts, the filesystem failure/cancel/retry contract and manual/catalogue synchronization pass separately. Generation 22 has identical production migration code and passes project state (57), Arrangement (16), MIDI routing (29), merge (7), snapshot (10), native codec (9), project import (6) and audio delivery (16) regressions. The audio-delivery group includes the existing five-minute realtime/export comparison. Ignored tests are counted separately; the eight native migration tests are explicitly executed, not counted as passing from their ordinary ignored run.

The first generation 24 native group had two UI deadline failures while native linking competed for resources. The complete unchanged group was rerun without a competing build and passed 8/8. Both logs remain in the [receipt](ableton-migration-receipt.json), along with earlier corrected compilation and linker failures. These builds disable optimization/debug information for the root crate, use one build job and disable incremental compilation. They do not establish optimized release performance.

The private saved Live 11 default Set is read without modification and reports its six tracks, eight scenes and 23 differences. That is a structural installation smoke test. It is not the required user-authored Live 10/11 reference session, source-app playback comparison or listening acceptance. Those comparisons, producer-library discovery, controller acquisition and the retained audio/hardware/live-release criteria remain pending. The installed powered-hub app and saved user sessions were preserved. This receipt makes no new physical-control, hardware-loopback, audible or stage-quality claim.
