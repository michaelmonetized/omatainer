# MIDI composition tools

The MIDI editor’s transformation menu offers Chord progression, Melody contour and Articulation. Preview generates ordinary editable notes in the draft. Keep retains them for manual editing; Restore returns the exact source; Apply publishes one change with Undo and Redo.

Chord progression has editable degrees, inversions and borrowed semitones, three or four voices, closed/open/drop-two voicings, octave spread and a bounded voice-leading search that minimizes movement without crossing voices. Register and chromatic permission are explicit. The native workflow creates an eight-chord Dorian progression, revises its inversion, restores and regenerates it, then applies, undoes, redoes, saves and reopens it.

Melody contour accepts an actual drawn 32-point shape, density, pitch variation, gate range, register, channel and a full-width unsigned seed. Repeating the seed repeats the musical data; rerolling regenerates from the original without accumulating notes. Ten different native saved alternatives reopen with their notes intact. A manually edited note remains editable after the generator preview is kept.

Articulation offers arpeggios, strums, grace notes, flams, glissandi, repeated notes and legato. Quantized events have positive duration and paired releases. Owned expression follows the generated note while unrelated automation remains unchanged. The native selector exercises Strum, Flam and Glissando and a subsequent single-note edit with one exact Undo/Redo.

The combined frozen source passed 2233 unfiltered ordinary Rust tests, zero failures and 73 audited ignored qualifications, production compilation, seventeen Node checks, all 42 focused groups, twelve native import workflows using a fresh source-bound worker, and unchanged output-clock limits at six tempos under actual concurrent decode/egui work. Seven composition engine tests and three native workflows join the retained eight note-variation engine checks, two native lane/seed workflows and an actual 2,000-loop rendering test.
