# Saved DJ effects layouts

Inspect layout loads it for review without changing playback. The review lists both names, slot order, enabled states, wet amounts, parameters, beat/manual timing, fader placement and deck/master/sampler routes. Foreign or deleted sampler routes require Bind to selected sampler track or Remove sampler route before review.

Review recall captures the current controls and project identity. Recall reviewed layout · reset tails fades both contributions to dry for exactly 5 ms, applies both units together and retires previous histories, then fades in for exactly 5 ms. A control or project/route change before commitment refuses recall. The panel waits for the actual renderer result. Cancellation controls apply to bounded file work; output-rate changes or audio-owner retirement cancel unfinished recalls and preserve the controls already in place.
