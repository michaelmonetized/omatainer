# Atomic scene properties (#227)

Scenes now retain independent names, RGB colors, optional tempo and time signature, launch timing and empty-slot behavior. The existing Session editor saves launch properties through one worker-prepared, guarded Undo transaction. Tempo is 40–240 BPM; meter uses the native song range of 1–255 beats and denominators 1–128. Disabled tempo/meter controls inherit the current clock. Duplicated scenes retain properties; deleted/reused slots receive fresh identities and defaults. Track and clip names remain independent.

One scene queues its stable identity, reviewed properties and effective boundary. All enabled occupied clips start at that boundary, with clip legato preserved and no separate re-quantization. Empty Stop finishes that track's recording take and releases clip notes at the boundary. Empty Keep leaves its existing material and physical input owners running. Add scene keeps empty tracks. Disabled cells remain untouched. A scene preserves the selected track, so ongoing recording and live input cannot be silently redirected by iterating its clips.

A chosen scene tempo or meter replaces song conductor automation from the launch, keeping musical beat and integrated elapsed time. An inherited scene leaves the conductor untouched. Explicit meter starts its downbeat at the effective boundary; tempo alone keeps current meter and pickup phase. Odd-meter click, count-in, labels, bar launch and Repeat grids share the same flat timing state. The tempo change takes effect inside the exact output sample, including beat-dependent effects and MIDI clock, without a new external transport Start/Stop. This flat clock is the current clock, not a retained historical automation map; native conductor editing/import can replace it, and Undo restores it.

The latest requested scene replaces an older pending one. Toggle of the queued scene and Cancel queued scene discard it without stopping current clips. Stop, seek, safety recovery, native replacement, deletion and changed launch properties discard pending work; reordering preserves identity. Names, reviewed/current properties, queue boundary, meter and refusal state are available in snapshots, bounded ordinary/streaming IPC status and native accessibility descriptions. Participating grid cells also show queued state. IPC names are bounded to 256 escaped bytes and expose truncation; unchanged cached status performs no heap work. No physical controller display qualification is claimed.

Native state schema 23 persists scene properties and the current meter/phase/click settings. Pending launch and active identity are transient and never restart on reopen. State 22 without these fields migrates; old headers refuse injected fields, including null/default-valued properties. Current validation refuses track-owned scene properties, invalid tempo/meter/phase, and a simultaneous flat scene clock plus conductor. Track configuration templates retain their existing scope.

Software qualification uses the actual native renderer, egui/AccessKit handlers, MIDI clock scheduler, socket replies and real project containers. It opens no physical audio/MIDI device and no additional GUI. Existing independent stage processes remain unchanged.
