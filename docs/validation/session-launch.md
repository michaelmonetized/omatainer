# Session launch modes, musical timing and legato

Issue [#196](https://github.com/michaelmonetized/omatainer/issues/196) adds per-clip Trigger, Gate, Toggle and Repeat policies to the native Session clips manager. Primary mouse, Space/Enter, assistive actions, learned clip assignments and the APC grid share the source-owned press/release path. Trigger starts on press and keeps playing after release. Gate holds until its quantized release; releasing before onset cancels it. Toggle uses separate press edges to start, schedule stop or cancel that stop. Repeat retriggers while held and stops on its release boundary. Explicit one-shot and loop actions retain their deliberate loop choice while using the clip's timing and legato setting.

Timing can inherit the global value or choose Immediate, 1/16, 1/8, 1/4, 1/2 or 1/2/4/8 bars. The beat divisions use quarter-note coordinates. Bar groups use the project's actual meter, first complete bar after a pickup, and global bar numbering through aligned or fragmentary meter changes. Repeats recalculate the next musical boundary as the meter changes. A positive beat subdivision rejoins the absolute beat grid after an immediate stopped launch between beats. Immediate Repeat uses the clip length relative to its launch; positive inherited divisions are bounded to at least 1/64 of a whole note. No boundary enumeration allocates on the renderer.

An explicit pending start leaves the prior clip playing until its exact sample boundary. A held release retains the original project namespace, track, scene and generation even when selection, bank, mapping or another input changes. Older releases cannot stop a newer owner. Release capacity is reserved through the native retained-identity wrapper, including a full ordinary command queue. Disconnect emits the matching release. Emergency stop discards held clip state before explicit recovery. Seek cancels future transitions and repeat but keeps active release ownership. Structural scene removal retires its queued/repeating transition; stale targets refuse without renderer allocation.

Legato carries elapsed musical phase modulo the destination clip's own period, including unequal lengths. The renderer releases old clip-owned notes and external routes while preserving live input voices, then chases the new clip's current notes. Queued starts and stops are separate, so an old release can stop its owner without erasing an unrelated next start. Native grid and accessibility state distinguish queued, playing, stop queued and stopping; alternate actions cancel a pending transition. Pointer release outside the grid, keyboard release, focus loss and window focus loss retain their original target. Assistive click toggles Gate/Repeat holds; explicit Press/Release actions are also available.

Native state schema 21 persists policies with clip properties in Session and Arrangement snapshots. Older schemas and `.omatclip` schema 20 migrate omitted defaults but reject injected launch fields. Native containers and presets reopen the exact policy. Remembered Gate/Repeat clips cannot resume without a new held input. A running clip must stop before its properties can be edited through the existing atomic manager.
