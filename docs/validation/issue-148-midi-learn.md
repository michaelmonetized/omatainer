# Learn performance MIDI controls

The native MIDI panel chooses an implemented action, deck or track slot, cue/scene/track/effect number, and compatible message class. Relative encoders require explicit offset-binary or two's-complement decoding and sensitivity; Browse uses one row per decoded step. Pitch can select complete 14-bit pitch bend. No motorized wheel protocol is inferred.

Capture binds its target before input and accepts one complete compatible gesture from a unique exact device name/backend port id and channel. Other messages keep normal routing. Note releases and zero-velocity presses cannot finish capture; repeated captured presses wait for explicit review. Show the device, channel, message address, value and target, then Add or deliberately Replace its conflicting address. Built-in and learned conflicts are visible. Test admits the captured action through existing performance/project/history/output guards, and the normal control or load receipt remains authoritative. Shift is tested after assignment through its following hardware gesture.

Assignments are limited to 256 records and 64 KiB per profile; targets, message families, relative metadata, exact endpoints and overlapping addresses validate before publication. Saved addresses override their built-in action only. Removing restores any built-in action. Edit preserves the wire address and requires a compatible action. Selected row revisions prevent profile changes or other configuration replacements from retargeting Edit/Remove. Missing or ambiguous exact ports remain unavailable; no guessed-device fallback applies.

The native callback copies bounded messages and reads atomics only. Learning, parsing, configuration, logging and command admission remain on dispatch workers. Learning/configuration boundaries release older source gates and fence queued prior messages, retaining raw realtime and built-in safety-stop meaning. Learned relative controls cannot inherit absolute-CC coalescing. Cancel/Escape/close return subsequent input to normal dispatch; capture times out after 30 seconds. Disconnect cancels uncommitted capture while retaining installed records. Existing connection discovery requires explicit Retry/rescan or input-worker teardown; automatic USB hotplug detection is not claimed.

Add/Replace/Edit/Remove affect the current run. Save uses the existing bounded preferences owner and exact file-revision check; the active profile changes only on its durable receipt. Save conflicts preserve the external file, installed live assignments and prior saved profile. Unfinished preference edits disable MIDI Save so its receipt cannot discard them. Restore saved assignments is explicit. Preferences version 12 persists these mappings; versions 1–11 migrate to empty learned records and cannot smuggle the new field. Future versions and unknown fields reject.

The old ignored LearnCapture command and legacy learning flag are removed. There is one working capture/assignment owner.

All 1498 ordinary tests pass on the source-bound build in [combined qualification](remaining-backlog-qualification.md). Native egui fixtures deliver actual synthetic wire messages through the bounded callback and dispatch worker, test actions and conflicts, edit/remove/cancel/close/disconnect, and exercise real durable profile storage and file conflicts. Physical Pioneer, Numark, Akai and keyboard capture/assignment/disconnect and final listening remain pending attachment. No physical controller or NS7 driver compatibility is claimed.
