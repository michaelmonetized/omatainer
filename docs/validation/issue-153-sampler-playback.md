# Sample slot playback modes

Each sample slot saves Trigger, Hold or Toggle, repeat and an optional source-time cue. Trigger restarts at the cue on a new press and continues after release. Hold ends on final local input release. Toggle ends on its next press, including after the selected bank changes. Repeat preserves fractional source-time overshoot and wraps to the cue inside the exclusive trim range. Active voices retain their source, gain, mode, cue, repeat and destination across bank changes and edits. Native source sample rates remain independent of output rate. Audition remains a separate one-shot preview.

The bank editor prepares and validates cue/range changes before Apply or reusable Save. Invalid drafts leave the installed bank untouched. Project schema 12 and reusable-bank schema 2 retain playback settings; older valid records load with legacy Trigger defaults. Legacy headers containing new playback fields, including null/default objects, reject without altering the original file. A migrated reusable store writes only on explicit Save and retains its original backup.

Stop slot works from a pad context menu, focused Shift+Escape, selected-slot editor button/Shift+Escape and learned Note button with exact slot 1–16. Each slot has independent reserved queue space. Pending stops fence matching starts until renderer acknowledgment, while other slots and transport remain independent. Releases retain their existing FIFO reservations. A physically held local input must be released before the next press. Small test queues preserve their prior ordinary budget with 16 added stop positions; production remains bounded at 256 commands.
