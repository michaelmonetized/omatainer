# Chromatic cue pads

Choose Pitch Cue in a deck's performance-pad panel, choose an existing cue as its root, and select Low, Center or High. The eight pads show their semitone offsets: Low spans −6 through +1, Center −3 through +4 and High −1 through +6. Every range includes the original note. Shift+pad selects the root; pad parameters select a range, or cycle existing cues with Shift. Original Key restores the saved deck key through the ordinary undoable key control.

Each press retriggers the selected cue immediately, retaining the deck's quantize preference. Pitch follows the newest admitted held pad; releasing it returns to an older surviving hold or the saved deck key. A paused deck auditions its cue and returns when its last gate ends; an already-playing deck continues from its current position. Tempo stays independent. Mode, root/range, focus and media changes retire original actions; late releases remain safe. Other decks, master gain and ordinary held Cue ownership remain intact.

Existing key-lock DSP handles forward ratios 0.5–1.5. Scratch, reverse and unsupported rates bypass cue pitch with the consequence shown in the native panel. Root/range choices are transient, like existing pad modes; original key changes and cue points use existing saved state. The nine-mode MIDI Learn chooser saves and reopens the ninth learned mode without changing any manufacturer's original eight mode numbers or emitting a new hardware address.
